Pattern

Subpanels

A second panel fed from a breaker in the main one. It has its own layout and a short code that prefixes its breaker numbers (“G6”). Its feeder breaker is shown as “→ Garage subpanel” with a SUB tag. Anything about cutting power knows that the feeder kills everything downstream.

Add subpanel
Short code prefixes every breaker in it (G1, G3/5). The feeder’s label becomes the subpanel’s name. Subpanels usually have main lugs instead of a main breaker — the feeder is the shutoff.
